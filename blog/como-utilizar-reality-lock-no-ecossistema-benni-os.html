Executive Summary & The Problem Space

In modern autonomous agent development, the most dangerous bug is not an explicit exception, a stack trace, or an HTTP 500 status code. The most dangerous failure mode is what we term the Hallucination of Done.

Consider an autonomous database migration agent tasked with running a schema update:

User: "Migrate the production PostgreSQL database schema and verify table constraints."
Agent: "I have successfully migrated the schema, created table 'users_v2', and verified all 4,200 records."

In reality:
- The database connection pool timed out after 30 seconds.
- The underlying subprocess exited with exit code 1 (Fatal Error).
- The transaction was rolled back by PostgreSQL.
- Zero tables were created, and zero rows were migrated.

Because Large Language Models (LLMs) are autoregressive probabilistic engines trained on human conversational patterns, their primary objective function is linguistic coherence and helpfulness, not physical ground truth. When an LLM encounters ambiguous error strings or partial execution traces, its sampling distribution heavily biases toward asserting success rather than reporting failure.

In mission-critical systems (finance, infrastructure management, automated CI/CD, healthcare, and robotics), the Hallucination of Done leads directly to data corruption, silent downtime, and unrecoverable cascade failures.

To eliminate this vulnerability at the mathematical level, we developed reality-lock — a deterministic physical evidence verification gate that separates agent intent from physical execution, requiring non-repudiable operating system and database proofs before issuing an immutable SHA-256 Merkle receipt.

2. Mathematical Formalization of Physical State Transition

Let the physical state of the host operating system at timestamp $t$ be represented by $\mathcal{S}_t$.

When an agent executes an action $A$, it asserts a transition from pre-state $\mathcal{S}t$ to post-state $\mathcal{S}{t+1}$.

Standard agent frameworks rely on the LLM's internal representation:

$$\mathcal{P}(\text{"Done"} \mid A, \mathcal{S}_t) \approxpprox 0.98 \quad\text{(Stochastic Guess)}$$

reality-lock introduces a formal verification function $\mathcal{V}(A, \mathcal{S}_{t+1}) \to {0, 1}$:

$$\mathcal{V}(A, \mathcal{S}{t+1}) = \beginegin{cases}
1 & \text{if }\text{Hash}(\text{Disk}(\mathcal{S}{t+1})) = H_{ ext{expected}} \;\land\;\text{ExitCode}(A) = 0 \
0 & \text{otherwise}
\end{cases}$$

The non-repudiation Merkle receipt $\mathcal{R}$ is computed as:

$$\mathcal{R} = \text{SHA-256}\Big(\text{ActionID} \,|\,\text{Timestamp} \,|\,\text{ExitCode} \,|\, H_{\text{disk}} \,|\, H_{\text{witness}}\Big)$$

If $\mathcal{V} = 0$, the lease fails, a HallucinationOfDoneException is raised, and the rollback hook restores the pre-state snapshot $\mathcal{S}_t$ from an atomic copy-on-write buffer.

import hashlib
import os
import subprocess
import time
import json
from enum import Enum
from typing import Dict, Any, Optional, Callable, List

class VerificationStatus(str, Enum):
    VERIFIED = "verified"
    REJECTED = "rejected"
    QUARANTINED = "quarantined"

class ExecutionReceipt:
    """
    Cryptographically verifiable proof of physical execution.
    """
    def __init__(
        self,
        action: str,
        status: VerificationStatus,
        observed_hash: str,
        expected_hash: str,
        exit_code: int,
        duration_ms: float,
        details: Dict[str, Any]
    ):
        self.action = action
        self.status = status
        self.observed_hash = observed_hash
        self.expected_hash = expected_hash
        self.exit_code = exit_code
        self.duration_ms = duration_ms
        self.details = details
        self.timestamp = time.time()
        self.merkle_digest = self._compute_merkle()

    def _compute_merkle(self) -> str:
        payload = (
            f"{self.action}:{self.status.value}:{self.observed_hash}:"
            f"{self.exit_code}:{self.timestamp}:{json.dumps(self.details, sort_keys=True)}"
        )
        return hashlib.sha256(payload.encode("utf-8")).hexdigest()

    @property
    def is_valid(self) -> bool:
        return self.status == VerificationStatus.VERIFIED and self.exit_code == 0

    def to_dict(self) -> Dict[str, Any]:
        return {
            "action": self.action,
            "status": self.status.value,
            "merkle_digest": self.merkle_digest,
            "observed_hash": self.observed_hash,
            "expected_hash": self.expected_hash,
            "exit_code": self.exit_code,
            "duration_ms": round(self.duration_ms, 3),
            "timestamp": self.timestamp,
            "details": self.details
        }

class FileSystemVerifier:
    """
    Inspects physical file existence and SHA-256 byte digest on disk.
    """
    def __init__(self, target_path: str, expected_hash: Optional[str] = None, min_bytes: int = 1):
        self.target_path = target_path
        self.expected_hash = expected_hash
        self.min_bytes = min_bytes

    def verify(self) -> Tuple[bool, str, Dict[str, Any]]:
        if not os.path.exists(self.target_path):
            return False, "file_missing", {"error": f"Path '{self.target_path}' does not exist on physical disk."}

        file_size = os.path.getsize(self.target_path)
        if file_size < self.min_bytes:
            return False, "file_empty", {"error": f"File size {file_size} bytes is below threshold {self.min_bytes}."}

        hasher = hashlib.sha256()
        with open(self.target_path, "rb") as f:
            while chunk := f.read(65536):
                hasher.update(chunk)
        digest = hasher.hexdigest()

        if self.expected_hash and digest != self.expected_hash:
            return False, digest, {
                "error": "Hash mismatch",
                "observed": digest,
                "expected": self.expected_hash
            }

        return True, digest, {"size_bytes": file_size, "path": self.target_path}

class RealityLockEngine:
    """
    Zero-Trust execution verifier. Halts Hallucinations of Done.
    """
    def __init__(self, strict_mode: bool = True):
        self.strict_mode = strict_mode
        self.audit_log: List[ExecutionReceipt] = []

    def verify_and_seal(
        self,
        action: str,
        verifier: FileSystemVerifier,
        execution_cmd: Optional[List[str]] = None,
        rollback_fn: Optional[Callable[[], None]] = None
    ) -> ExecutionReceipt:
        start = time.perf_counter()
        exit_code = 0
        cmd_output = ""

        # Step 1: Execute physical action if command provided
        if execution_cmd:
            try:
                proc = subprocess.run(
                    execution_cmd,
                    capture_output=True,
                    text=True,
                    timeout=30
                )
                exit_code = proc.returncode
                cmd_output = proc.stdout if exit_code == 0 else proc.stderr
            except Exception as e:
                exit_code = -1
                cmd_output = str(e)

        # Step 2: Physically inspect post-condition evidence on disk
        passed, observed_hash, details = verifier.verify()
        elapsed_ms = (time.perf_counter() - start) * 1000

        if passed and exit_code == 0:
            status = VerificationStatus.VERIFIED
        else:
            status = VerificationStatus.REJECTED
            if rollback_fn:
                try:
                    rollback_fn()
                    details["rollback"] = "executed_successfully"
                except Exception as rb_err:
                    details["rollback_error"] = str(rb_err)

        receipt = ExecutionReceipt(
            action=action,
            status=status,
            observed_hash=observed_hash,
            expected_hash=verifier.expected_hash or "any_valid",
            exit_code=exit_code,
            duration_ms=elapsed_ms,
            details=details
        )
        self.audit_log.append(receipt)
        return receipt
