Deterministic Zero-Cloud Evaluation for AI Agents: Eliminating LLM-Judge Token Burn via Cryptographic Receipts

The Crisis of LLM-as-a-Judge

Modern AI evaluation frameworks like DeepEval, Ragas, and LangSmith rely on asking GPT-4o or Claude 3.5 Sonnet to score agent runs on arbitrary 1-to-5 scales.

This approach introduces three fatal engineering flaws:

  • Extreme Token Waste: Evaluating a 20-step agent benchmark burns over 50,000 evaluation tokens per run.
  • Flaky Benchmarks: Running the identical evaluation prompt twice on the same model returns different scores due to stochastic temperature sampling.
  • Cloud Dependency: Testing cannot run offline or inside air-gapped CI/CD environments.

The Solution: Invariant Assertion Matrices

agent-eval-harness validates AI agent trajectories against formal programmatic invariants rather than linguistic opinions.

  1. State Postcondition Verification: Checks whether real files, schemas, or network states were modified correctly according to strict regex, JSON-schema, or byte hash proofs.
  2. Zero Token Consumption: Runs entirely in Python without sending a single API call to OpenAI, Anthropic, or any third-party provider.
  3. SHA-256 Merkle Receipts: Produces immutable verification hashes that can be committed to Git or public CI audit trails.
