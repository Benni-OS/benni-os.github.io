1. The Frontier Overkill Problem in Agentic Coding

Every autonomous coding session with Claude Code follows a predictable distribution: roughly 20% of turns involve high-leverage architectural reasoning, cross-module debugging, or subtle race conditions. The remaining 80% are mechanical—reading directory trees, summarizing stack traces, formatting boilerplate, running test retries, or parsing verbose JSON tool outputs.

Without a routing layer, every single one of those mechanical turns hits a frontier cloud endpoint at full context-window pricing. Worse, when a tool call returns a 12,000-token build log or an untouched 900-line TypeScript module, that raw payload rides along in the conversation history for every subsequent turn.

  • Uniform Frontier Pricing on Routine Turns: Asking a frontier model to acknowledge a clean git status or extract a line number from a compiler error wastes both dollars and 1,500+ ms of cloud round-trip latency.
  • Unbounded Tool-Output Bloat: Raw terminal logs, test suites, and full-file reads compound context size quadratically across a 30-turn session.
  • Redundant Tool-Call Re-evaluation: Agents repeatedly inspect unchanged files and static schemas across sub-turns, paying full input token costs each time.
Core Architectural Shift: Pointing ANTHROPIC_BASE_URL at Benni-OS/claude-code-router inserts a zero-modification local control plane between Claude Code and upstream inference—cutting total API spend by 75% while keeping frontier reasoning intact for complex turns.

3. Four Core Mechanisms Behind the 75% Cost Reduction

1. Sub-Millisecond Complexity Classification

Using an LLM to route an LLM adds latency and cost. Instead, claude-code-router runs a deterministic scoring function in under 0.4 ms. It inspects payload token count, tool-call chain depth, AST symbol density, diff hunk count, and domain signals (e.g., concurrency, security, multi-file refactor) to assign Tier 0, Tier 1, or Tier 2.

2. Local GPU Offload (benni-inference-engine / Ollama)

Routine Tier 0 turns—file summarization, test-log triage, simple edits, and commit-message synthesis—are translated on the fly to OpenAI-compatible local inference endpoints such as benni-inference-engine or Ollama running on an 8 GB+ local GPU at $0.00 marginal token cost. If the local engine is offline or exceeds a latency ceiling, the router fails over automatically to Claude Haiku.

3. AST & Log Context Compaction

Before forwarding any message history upstream, the compactor scans tool_result blocks. Oversized source files are reduced to AST skeletons (imports, class/function signatures, type annotations, and active line windows around errors), while repetitive test logs are collapsed into unique failure signatures and stack frames.

4. SQLite WAL Tool-Result Cache

Repeated read-only tool outputs and deterministic sub-turn prompts are hashed (SHA-256) and stored in a local SQLite database configured with PRAGMA journal_mode=WAL. Concurrent subagents can read cached tool results in under 0.3 ms without write-lock contention.

5. Inside the Router: Sub-ms Classifier, AST Compactor & SQLite WAL Cache

The Python snippet below illustrates the three core hot-path components inside claude-code-router: deterministic complexity scoring, AST/log compaction for oversized payloads, and lock-free SQLite WAL caching:

import ast
import hashlib
import sqlite3
import time


COMPLEX_SIGNALS = ("race condition", "migration", "architecture", "security", "deadlock", "refactor")


def classify_turn(prompt_text: str, token_count: int, tool_depth: int) -> str:
    """Classify turn complexity in < 0.4 ms without any LLM call."""
    lowered = prompt_text.lower()
    score = 0.0
    score += min(token_count / 12000.0, 0.45)
    score += min(tool_depth * 0.08, 0.25)
    if any(sig in lowered for sig in COMPLEX_SIGNALS):
        score += 0.35

    if score <= 0.35:
        return "tier_0_local"
    if score <= 0.68:
        return "tier_1_fast"
    return "tier_2_frontier"


def compact_python_ast(source: str, max_chars: int = 2400) -> str:
    """Strip function bodies while preserving signatures, classes, and docstrings."""
    if len(source) <= max_chars:
        return source
    try:
        tree = ast.parse(source)
    except SyntaxError:
        lines = source.splitlines()
        return "\n".join(lines[:30] + ["... [compacted] ..."] + lines[-30:])

    skeleton = []
    for node in tree.body:
        if isinstance(node, (ast.Import, ast.ImportFrom)):
            skeleton.append(ast.get_source_segment(source, node) or "")
        elif isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef)):
            header = (ast.get_source_segment(source, node) or "").splitlines()[0]
            skeleton.append(f"{header}  # ... [body compacted]")
    return "\n".join(skeleton)


class WalToolCache:
    def __init__(self, db_path: str = ".benni/router_cache.db") -> None:
        self.conn = sqlite3.connect(db_path, check_same_thread=False)
        self.conn.execute("PRAGMA journal_mode=WAL;")
        self.conn.execute(
            "CREATE TABLE IF NOT EXISTS tool_cache (key TEXT PRIMARY KEY, payload TEXT, expires_at REAL)"
        )
        self.conn.commit()

    def get(self, tool_name: str, args_json: str) -> str | None:
        key = hashlib.sha256(f"{tool_name}:{args_json}".encode("utf-8")).hexdigest()
        row = self.conn.execute(
            "SELECT payload, expires_at FROM tool_cache WHERE key = ?", (key,)
        ).fetchone()
        if row and row[1] > time.time():
            return row[0]
        return None

Frequently Asked Questions

How does ANTHROPIC_BASE_URL enable hybrid routing without modifying Claude Code?
Claude Code respects the standard ANTHROPIC_BASE_URL environment variable for all Anthropic Messages API requests. By pointing ANTHROPIC_BASE_URL to http://127.0.0.1:4100, claude-code-router acts as a transparent local reverse proxy that inspects turn complexity, compacts oversized payloads, checks the SQLite WAL cache, and dispatches either to a local GPU (benni-inference-engine or Ollama), Claude Haiku, or Claude Sonnet/Opus.
How fast is the turn complexity classifier in claude-code-router?
The deterministic heuristic classifier runs in under 0.4 ms using zero LLM calls. It scores token count, tool-call depth, AST symbol density, diff size, and architectural keywords to assign each turn to Tier 0 (Local GPU), Tier 1 (Haiku), or Tier 2 (Sonnet/Opus).
What does AST Context Compaction strip before sending requests to the cloud?
AST Context Compaction parses bloated tool results—such as 8,000-line log dumps, full test outputs, or untouched file bodies—keeping function signatures, type definitions, imports, error stack frames, and active diff hunks while folding dead boilerplate. This shrinks prompt payload sizes by 55% to 78% without losing structural accuracy.
Why use SQLite WAL for caching repeated tool results?
Coding agents frequently re-run identical read-only tool calls across adjacent turns. Storing normalized request and tool-result hashes in SQLite with Write-Ahead Logging (WAL) enables concurrent, lock-free reads in sub-millisecond time, eliminating redundant inference and API spend.
